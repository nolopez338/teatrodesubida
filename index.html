Materiales

Materiales para Tres traumas treintañeros

Transversal

  • Ropa negra neutra y unificada para todos. Traer propuesta el miércoles.

Guerra

  • Sombrero para el general Esteban.
  • Sombrero para la generala Aura.
  • Sombrero para el general Nico.
  • Sombrero para la soldada Oli.
  • Bota o recipiente para el trago.
  • Un tratado resistente al abuso.
  • 3 gafas negras.
  • 3 sombrillas.
  • Tabla y ruedas para poner ratones.
  • Trampa para ratones.
  • Cuerda.

Mujer

  • Tubos de PVC para construir el rifle.
  • Mallas.
  • Bolsa plástica de supermercado.
  • 2 moñas (por pensar).

Ser o no ser

  • Tubos de PVC para construir la estructura del espejo.
  • 2 cuellos de lechugilla elegantes.
  • Luces navideñas.
  • Tela para tapar el armatoste.
